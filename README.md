# ALU Plast Čapljina – web stranica

Statična web stranica za **ALU Plast** (PVC i ALU stolarija po mjeri, Zvirovići, Čapljina).

- `index.html` – cijela stranica (naslovnica, Proizvodi, PVC program, ALU program, Reference, O nama, Kontakt; HR i EN)
- `img/` – fotografije, presjeci profila i logotipi

Stranica ne treba server ni bazu: otvori `index.html` ili prenesi sadržaj na bilo koji hosting (public_html / www).
Može se objaviti i preko GitHub Pages (Settings → Pages → Branch: main, folder: / root).
